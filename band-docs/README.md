# Band Docs — Bryce Beene Music

This folder is the single source of truth for all band documentation.
Everything is plain Markdown. You do not need any special software to read it —
any text editor, phone, or browser will work.

---

## What's In Here

| Folder | What It Contains |
|--------|-----------------|
| songs/chord-charts/ | Chord-over-lyric charts, one file per song |
| songs/number-charts/ | Nashville Number System charts, one file per song |
| songs/_index.md | Master list of every song — key, tempo, feel |
| setlists/ | Setlists by date and venue |
| gigs/ | Show-day info sheets — load-in, pay, backline, roster |
| rehearsals/ | Rehearsal plans and post-rehearsal notes |
| roster/ | Band members and fill-in contacts |

---

## File Naming Convention

| Type | Format | Example |
|------|--------|---------|
| Songs | song-title.md | ring-of-fire.md |
| Setlists | YYYY-MM-DD_venue-name.md | 2026-04-15_blue-light-bar.md |
| Gigs | YYYY-MM-DD_venue-name.md | 2026-04-15_blue-light-bar.md |
| Rehearsals | YYYY-MM-DD.md | 2026-04-10.md |

- All filenames: lowercase, hyphens, no spaces
- All dates: YYYY-MM-DD so files sort chronologically

## How to Read a Chord Chart

Chords appear in brackets directly above the word where the chord changes.

The chord changes on the word directly below it.

---

## How to Read a Number Chart

Numbers represent scale degrees in the current key.
The key is always listed at the top of the chart.

| Number | Chord in Key of G |
|--------|------------------|
| 1 | G |
| 2 | Am |
| 3 | Bm |
| 4 | C |
| 5 | D |
| 6 | Em |
| 7 | F#dim |

Common symbols:

| Symbol | Meaning |
|--------|---------|
| ^ | Push (anticipate the beat) |
| _ | Hold |
| > | Accent |
| ( ) | Tacet / lay out |
| [ ] | Repeat previous bar or section |
| tr | Turnaround |
